# SAG

프로젝트 웹사이트: https://h2w1.github.io/SAG/

## 페이지 수정

1. `index.html`을 열고 연필(Edit) 버튼을 누릅니다.
2. 원하는 내용을 수정하고 `Commit changes`로 `main` 브랜치에 저장합니다.
3. GitHub Pages가 자동으로 다시 배포됩니다.

## 나중에 채울 항목

- 저자 및 소속: `Authors & affiliations [TBD]`가 있는 부분을 수정합니다.
- 논문과 공개 코드 링크: 해당 버튼의 `href="#"`를 실제 URL로 바꾸고, `btn-disabled` 클래스와 `aria-disabled="true"`를 제거합니다. 버튼의 `[TBD]` 문구도 지웁니다.
- 이미지와 영상: `figure/` 폴더에 있습니다. 파일명과 대소문자를 유지하면 기존 링크가 그대로 작동합니다.

페이지 디자인과 본문, 실험 결과, 이미지 및 데모 영상은 이전 페이지의 내용을 옮긴 것입니다.
